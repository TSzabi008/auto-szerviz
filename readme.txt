Apex AutoWorks

A simple website for a fictional car repair shop, created using HTML, CSS and JavaScript.

-Pages

- Home: Introduces the garage and displays the main services.
- About: Provides information about the company, its history and its team.
- Services: Shows the available car repair services.
- Contact: Contains a service request form where visitors can enter their contact details, car information and select the service they need.

-Technologies
- HTML
- CSS
- JavaScript

-Note
The contact form is a frontend demonstration and does not send data to a real server.
